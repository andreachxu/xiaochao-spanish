陈晓超专属平台 — versión inicial

Incluye interfaz responsive y navegación, detalle de tareas, ejercicios básicos, vocabulario, gramática, lectura, pronunciación, progreso y panel de profesora de demostración.

IMPORTANTE: esta versión todavía no está conectada a Supabase. Los datos se guardan en el navegador (localStorage), así que no se sincronizan entre dispositivos. El selector de roles no es seguridad real. No introduzcas información privada hasta configurar autenticación y políticas RLS.

No contiene claves ni servicios de pago. El siguiente paso es publicar la web y conectar cuidadosamente el proyecto Supabase ESPAÑOL existente.
